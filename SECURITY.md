# Security Policy

## Reporting a vulnerability
Email security@traceatlas.example (replace with the real address before public release).
Please do not open public issues for security problems.

## Scope
- Multi-tenant isolation and RBAC/ABAC enforcement
- SSRF and egress controls on every connector
- Prompt/tool injection defenses around the AI gateway
- Malicious document/media handling (sandbox + quarantine)
- Evidence custody and audit integrity

## Supported versions
Only the latest release is supported until a versioned support policy is published.
